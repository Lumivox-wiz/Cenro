## 0. 判定口径

| 项 | 说明 |
|---|---|
| 计为冲突 | 同一字段 / 阈值 / 规则 / 枚举在两个以上位置取值不同，且无法用「版本先后」解释 |
| 仍计但标注 | 文档自陈落后（UX v1.2 对 UI v1.11）——标为「已知落后」 |
| 不计为冲突 | 修订过程中的建议值 → 采纳后调整值（属正常收敛）；文档自己写明「历史起点 / 已被取代」的表述 |

### 4.2 判定方法

1. 同一事实（字段、阈值、枚举、色值、版本号、计数）在 ≥2 处出现且取值不同 → 逐条记录。
2. 可复算项一律重算：67 项矩阵求和、21/67 百分比、10/6.5 倍数、WCAG 对比度、3 组项数求和。
3. 对文档自陈「历史起点 / 已被取代 / 已裁决」的表述不重复计入，但若其所在章节仍被当作现行规范引用，则计入。
4. **不采信**「另一份文档已说明」作为消解理由——只要两处都被引用为现状，就计为冲突。
