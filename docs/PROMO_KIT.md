# 岑序（CENRO）宣传素材包

版本：对应 v0.20.9 · 2026-11-18
用途：官网首屏 / GitHub README / 社区发布帖 / 短视频封面 / 应用商店占位图

---

## 0. 一页速览

| 项 | 内容 |
|---|---|
| 名称 | 岑序 · CENRO（"岑"= 小而高的山，"序"= 次第排列） |
| 品类 | 本地优先的多格式阅读器（Windows / Android，同步 Linux·macOS 方向） |
| 核心功能 | 小说（EPUB·TXT·MOBI·AZW3·FB2·MD·HTML·DOCX·RTF·MHTML）、漫画（CBZ·CBR·CBT·CB7·ZIP·图片夹）、PDF，三者共用一个书架与一套标注体系 |
| 目标用户 | 书与漫画混着看、文件散在硬盘各处的人；对在线书源、账号、云同步有戒心的人；愿意为"东西在我手里"多走一步的人 |
| 一句话解决的痛点 | 为了读三种东西，得开三个 app，进度三份、书签三套、封面三处 |
| 核心价值 | 一个书架收全部；断网完整可用；标注跨格式统一且能导出 |
| 品牌调性 | 克制、纸感、界面退后。蓝是山脊的蓝，不是按钮的蓝 |

**说人话的主线**：不求功能最多，求"打开就有，关了还在"。

## 1. 主宣传语

> # 所有格式，一座书架。

**为什么是这句**

- 6 个字，两段对仗，朗读有落点；缩到 340px 宽的横幅也不糊。
- 前四字讲能力（多格式），后四字讲形态（统一），一句话把"多"和"一"的张力给足了。
- 不绑定具体数字。今天 16 种、明天 20 种，这句话不用改。

**配套副标**（主标语无法承载"本地优先"，由副标补足，二者必须同屏出现）

> 小说、漫画、文档 —— 不联网，不要账号，进度只存在本机。

**使用规范**

| 场景 | 写法 |
|---|---|
| 主 KV / 首屏 | 主标语两行断开，副标一行 |
| 只放得下一行 | 用主标语，删副标；不要压成一行长句 |
| 与 logo 竖排 | logo 在上、标语在下，间距不小于 logo 高度的 0.6 倍 |
| 禁止 | 不在主标语后加感叹号；不改标点为"所有格式·一座书架"（中点会削弱对仗） |

## 2. 三条备选短标语

三条不是同一个意思的三种说法，是三个不同战场的弹药，按场合取用。

| # | 标语 | 打的是哪一仗 | 适用位置 |
|---|---|---|---|
| A | **不必再开三个阅读器。** | 痛点，正面攻击。适合完全没听过产品的人，3 秒内建立"这跟我有关" | 社交平台文案、短视频首帧、投放素材 |
| B | **书在本地，进度也在。** | 隐私与所有权。"进度也在"是这句的钩子——多数人只想到文件，没想到进度 | 关于页页脚、隐私功能说明页、启动画面 |
| C | **读到哪儿，它记得。** | 场景。指向续读与跨格式进度恢复，一句话就是一个使用瞬间 | 应用商店截图配文、功能卡片标题 |

**组合用法**：主标语做门头，A 做拉新，B 做差异化，C 做留存。不要在同一个版面上同时出现两条以上。

## 3. 宣传图创意方案

### 3.1 视觉主题：书脊山脉 / The Spine Range

**概念推演**

- "岑"是小而高的山。而书架上一排竖立的书，轮廓本来就是山。
- "序"是次第。书脊等距排列，就是"序"最直白的图解。
- logo 本身是双峰加一道流动丝带。宣传图不重新发明图形，只**把 logo 拆开放大**：双峰 → 一排书脊的顶线；丝带 → 横穿书脊的一道光，末端垂下来变成书签。

**一句话概括画面**：一座由书脊堆成的山，一道光从山间穿过，光掉下来成了书签。

这个母题的好处：不需要画产品界面，不依赖截图，缩到 32px 图标仍可辨认。

### 3.2 构图（横版主 KV，1920 × 1080）

**分栏**：左 54% 文字，右 46% 图形。不用 5:5 —— 中文大标题需要呼吸，图形侧需要"挤"，山才有势。

| 区域 | 范围（px） | 内容 |
|---|---|---|
| 安全边距 | 四边内缩 120 | 所有元素不越线 |
| 文字区 | x 120–920 | logo、主标语、副标、功能点 |
| 图形区 | x 1020–1800 | 书脊山脉 + 丝带 + 书签 |
| 地平线 | y = 820，x 1020–1860 | 1px 横线，rgba(31,35,40,0.10)；书脊立于其上 |
| 右上留白 | x 1480–1860，y 80–280 | 空置，预留给二维码 / 商店标 / 平台角标 |

**书脊山脉的构造规则**

- 13 本，宽 44–72px 不等，间距 10–16px 不等（等距会变成栅栏，疏密才有山势）。
- 高度 220–620px。两个峰：左峰在 x≈1320，高 430；右峰在 x≈1700，高 620。右高于左，与 logo 的主次一致。
- 底部严格对齐 y=820，顶部自由错落——错落是唯一的"不规则"，其余全部规整。
- 最右那本最亮、最宽（72px），是全图视觉落点，视线从标语扫到图形，最后停在这里。

**丝带与书签**

- 一条宽 90–130px 的半透明白蓝渐变带，从左下 (1020, 760) 斜向右上 (1800, 560) 穿过全部书脊，跨过书脊处降低不透明度到 35%。
- 在 x≈1480 处收窄成 14px 宽的竖带，下垂至 y=910（越过地平线 90px），末端切一个 V 形缺口——这是书签的形。
- 丝带在整个画面上是**唯一有弧度的东西**，其余全是直线与直角。

**外框**

- 整张图内缩 24px 套一个 28px 圆角（连续曲率 squircle）的 1px 描边，rgba(31,35,40,0.06)。
- 作用：把 KV 读成"一张卡片"，与应用的圆角语言同源，也让画面在信息流里自带边界。

### 3.3 配色

主色直接取自项目 design token，不另造一套。

| 角色 | 浅色版（主用） | 暗色版（备用） | 说明 |
|---|---|---|---|
| 背景 | `#F3F4F6` → `#FFFFFF`（135° 浅灰到白） | `#17191E` → `#1A1B1E` | 浅灰在下、白在上，书脊才有"立起来"的对比 |
| 主文字 | `#1F2328` | `#E6E7E9` | |
| 次文字 | `#575E6A` | `#A0A3A9` | 副标、功能点 |
| 品牌蓝 | `#2F6FEB` | `#5B8DEF` | 强调色，全图占比不超过 12% |
| 书脊深蓝 | `#1E3F7A` / `#355FA3` | 同 | 取自 logo 渐变 |
| 书脊浅蓝 | `#5885CC` / `#87AEE6` | 同 | 最右那本用这组 |
| 中性书脊 | `#2B2F36` / `#3A4048` / `#555C66` | 同 | 10 本中的 10 本，低饱和，不抢蓝 |
| 丝带高光 | `#B9D2F5` → `#FFFFFF`（40%–72% 不透明） | `#ADC8F0` | |
| 暖色点缀 | `#F5EFE3` 压 6% | — | 取自阅读主题 sepia，铺在书脊顶部，抵消纯冷的疏离感 |

**配比原则**：中性色 70% / 深蓝 18% / 亮色 12%。蓝一旦超过 15%，画面从"安静"滑向"科技感"，与品牌调性相反。

### 3.4 字体

| 层级 | 中文字体 | 西文字体 | 字号 / 字重 / 字距 |
|---|---|---|---|
| 主标语 | 思源宋体 Source Han Serif SC Bold | — | 96px（画布宽 5%）/ 700 / -0.02em，行距 1.28 |
| 副标 | 苹方 PingFang SC / 思源黑体 Regular | Inter Regular | 20px / 400 / 0.01em，行距 1.6 |
| 功能点 | 同副标 | Inter Regular | 13px / 400 / 0.04em，行距 2.6 |
| 字标 CENRO | — | Inter Medium，全大写 | 22px / 500 / **+0.18em**（宽字距是字标的身份） |
| 字标 岑序 | 思源宋体 Medium | — | 22px / 500 / 0.06em |
| 角标版本号 | — | Inter Regular | 11px / 400 / #A8ADB5 |

**宋黑混排的理由**：主标语用宋，因为这是个"读文字"的产品，衬线的笔锋直接说明身份；副标与功能点用黑，保证小字清晰。反过来（黑标题+宋正文）会显得像政府公文。

**禁止**：不用手写体、不用圆体、不用描边字、不给标题加投影。

### 3.5 核心图形元素（三层，从前到后）

1. **书脊山脉**（主形）— 13 本竖立矩形，双峰轮廓。承担"多格式"的隐喻：形态各异，却站在同一条地平线上。
2. **丝带 → 书签**（动线）— 一道光横穿，末端垂成书签。承担"续读"的隐喻：停在哪里，光就落在哪里。
3. **界面圆角框**（氛围）— 1px squircle 外框。承担"这是一件做得认真的东西"的暗示，不说话。

三层各自管一件事，不重叠功能。缺书脊则空洞，缺丝带则死板，缺外框则像草稿。

### 3.6 图上文字排布

按视线路径从上到下、从左到右，共 5 级：

| 顺序 | 位置（x, y 基线） | 内容 | 对齐 |
|---|---|---|---|
| ① | 120, 130 | logo mark（56×34）+「CENRO ｜ 岑序」字标，二者同基线，中间 1px 竖线分隔，高 18px | 左 |
| ② | 120, 340 / 463 | 「所有格式，」/「一座书架。」两行，96px 宋体 | 左 |
| ③ | 120, 590 | 副标一行：「小说、漫画、文档 —— 不联网，不要账号，进度只存在本机。」 | 左 |
| ④ | 120, 660（细线）→ 706 / 744 / 782（三行文字） | 细线 64px 长；下接三行功能点（见下） | 左 |
| ⑤ | 1800, 1020（右端基线） | 「CENRO 0.20.9 · GPL-3.0」 | 右 |

**三行功能点的措辞**（每行不超过 18 字，逐行递减长度以形成刀锋形）

```
EPUB / MOBI / PDF / CBZ —— 十余种格式，一个入口
书签、划线、笔记，跨格式共用一套
隐私书架、本地备份，WebDAV 自己选
```

**留白纪律**：主标语左侧到画布边 120px，标语块下方到副标留 60px 空档。这 60px 是整张图最贵的地方，不要塞任何东西。

### 3.7 适配版本

| 版本 | 尺寸 | 调整 |
|---|---|---|
| 主 KV 横版 | 1920×1080 | 如上 |
| 竖版（手机 / 朋友圈） | 1080×1440 | 文字整体下移，标语改三行（所有格式，/ 一座 / 书架。不行——改为「所有格式，」/「一座书架。」保持两行），书脊山压缩到 y 960 以下，只露上半截，丝带从右侧穿入 |
| README Banner | 1280×400 | 只留 logo + 主标语 + 书脊山剪影，删副标与功能点，丝带降到 1 条 |
| 应用图标位 | 1024×1024 | 只取双峰 + 书签，无文字 |

### 3.8 执行红线

- 不给任何元素加投影、发光、玻璃模糊。纸感来自留白和 1px 线，不来自特效。
- 书脊上不放真实书名。一是版权，二是真书名会把图拉回"某一本书"的具体性，而这张图要说的是"所有"。
- 不放手机 / 笔记本样机。这类产品图一旦套样机，就变成"又一个 App"。
- 通篇不超过 3 种字号之外的视觉重量；蓝色只出现在书脊、丝带、logo 三处。

## 4. 需要补充的信息

以下是会改变方案的关键变量。标 ★ 的建议优先确认。

| # | 待确认 | 影响什么 |
|---|---|---|
| 1 ★ | 这套素材**投在哪**——官网首屏、GitHub README、酷安/B站发布帖、还是纯自用存档？ | 决定出图数量与信息密度。发布帖需要"下载方式"CTA，README 需要许可证与平台徽标，纯存档则只要一张 KV |
| 2 ★ | 是否**公开发布**？目前定位是"自用 + 开源、未上架任何商店" | 决定图上是否出现下载二维码、版本号、平台标；也决定要不要写"免费开源" |
| 3 ★ | 是否要**中英双语并置**？字标 "CENRO" 与"岑序"的权重怎么排 | 双语并置会让字标变宽 40%，标语区可用宽度减少，主标语可能要降到 88px |
| 4 | 图里能不能用**真实界面截图**或真实书名 | 截图可信度更高但会把"抽象山脊"的主题冲掉；真书名有版权与隐私问题（尤其隐私书架是卖点） |
| 5 | 品牌蓝是否**锁定** `#2F6FEB`／`#5B8DEF` | 应用支持"莫奈取色"跟封面走，宣传图是否也允许一版暖色（sepia）变体 |
| 6 | 是否有**必须出现的硬元素**：GitHub 地址、GPL-3.0 标识、作者署名 Lumivox | 这些都要占版面，越早定越好 |

前 3 项确认后即可出图；第 4–6 项可以边做边调。
