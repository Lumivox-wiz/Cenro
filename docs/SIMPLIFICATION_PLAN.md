# 减法方案：像 Linear 与备忘录一样干净

方向：目标简单、架构简单、设计简单、实现简单。
手段：砍掉标语、提示文字、次要标签；**凡是靠文案才能看懂的界面，改布局**。
约束：每一项决定同时提升 UX / DX / AX，且不破坏任何现有功能。

适用层：书架层 + 设置层 + 关于层（阅读层本来就克制，本轮不动）。

---

## 0. 三条判据

砍不砍、怎么砍，不能凭"看着乱"。本方案用三组可检验的判据。

### UX（人用）
| | 判据 |
|---|---|
| U1 | 一个视图只有一个主语（唯一实心强调色按钮） |
| U2 | 界面不靠副标题解释自己；看不懂就改布局，不加句子 |
| U3 | 留白与分组代替分隔线与说明文字 |

### DX（人写代码）
| | 判据 |
|---|---|
| D1 | 单一真相源：一个事实只存一处，子页改了摘要不会撒谎 |
| D2 | 可达性：改一句文案不用翻十个文件 |
| D3 | 分支收敛：平台 / 状态的 `if` 越少越好 |
| D4 | 删元素必须同时删它的样式，样式表不留孤儿规则 |

### AX（智能体用）
把界面当成**只能看静态快照、只能读可访问性树、不会悬停**的消费者来审视。

| | 判据 |
|---|---|
| A1 | **名称唯一**：每个可交互元素的可访问名唯一且可推断。同名不同义是最贵的一种冗余 |
| A2 | **状态在属性里**：选中 / 展开 / 当前项用 `aria-pressed` / `aria-expanded` / `aria-current` 表达，不靠旁边的句子 |
| A3 | **悬停即隐形**：只有 hover 才出现的信息，对快照消费者根本不存在。触屏用户和 agent 同病同源 |
| A4 | **冗余是成本**：同一事实说两遍 = 两处可能互相矛盾 + 每次读取都要多付 token |

> A3 是本轮最有价值的一条发现：它把"移动端看不见更多按钮"从触屏问题，
> 升级成所有非可视消费者的问题——**同一个修复同时修好触屏和 AX**。

## 1. 减法清单

### 1.1 关于页：标语与营销行（8 处）

| 原文案 | 处置 | 布局怎么改 |
|---|---|---|
| `在有序的空间里，自由地阅读与探索` | **删** | hero 缩成 logo + 名称 + 版本 |
| `Cenro · A space of your own.` | **删** | 同上 |
| `目录 · 缓存占用 · 封面重建` | **删** | 行内只剩标签 + 箭头；内容进子页自己看 |
| `字体 · 字号 · 行高 · 段距 · 版心` | **删** | 同上 |
| `启动 · 扫描 · 备份 · 错误` | **删** | 同上 |
| `顶栏 · 侧栏 · 抽屉 · 安全区` | **删** | 同上 |
| `应用不联网，请手动下载新版本`（检查更新行） | **删整行** | 应用不联网是事实，不需要在设置里声明 |
| `无账号 · 无上报 · 书籍与进度只存本机`（隐私行） | **删整行** | 同上，属应用承诺，不是设置项 |
| `© 2026 岑序` | **删** | 版本号已在 hero 里 |
| `已复制到剪贴板。` | **删** | 按钮文案已经是「已复制」 |

- **UX**：关于页从 5 屏信息压成 1 屏；不再有品牌口号。
- **DX**：删掉 2 个只有装饰作用的 CSS 类（`about-slogan` / `about-brandline`）与 1 个（`about-footer`），样式表不留孤儿。
- **AX**：少 10 段纯文本。agent 读关于页时拿到的是「名称 + 版本 + 4 个入口 + 格式清单」，而不是口号。

**保留**：格式清单（小说 / 漫画 / 文档三行）。它是**数据表**不是标语——用户判断"我的文件能不能导入"时要用它，删了是信息损失。
（遗留问题：这三行的分组是「小说 / 漫画 / 文档」，与侧栏的「文本 / 电子书 / 文档 / 漫画 / PDF」不是同一套分类法。本轮不动，仅登记。）

### 1.2 设置菜单：摘要只留"当前值"，删掉"内容预告"（8 项）

现状每个菜单项下面一行摘要，其中大多是**在预告子页里有什么**，而不是**当前是什么**。

| 分组 | 现状摘要 | 新摘要 | 处置 |
|---|---|---|---|
| 阅读 | `衬线 18px · 1.75 倍` | `衬线 18px` | 留值，删预告 |
| 主题 | `浅色 · 阅读纸色` | `浅色` | 留一个值；阅读主题在子页里看 |
| 背景 | `未设置` / `已设置 · 莫奈取色` | `未设置` / `已设置` | 留值，删预告 |
| 书库 | `3 个目录 · 缓存 128 MB` | `3 个目录` | 留值，删预告 |
| 备份 | `本地 zip · WebDAV` | — | **全删**：这是功能说明，不是当前状态 |
| 隐私 | `隐私书架 · PIN` | `未启用` / `已启用` | 改成真实状态 |
| 快捷键 | `12 个键位` | — | **全删**：数字没有决策价值 |
| 关于 | `v0.17.0` | `v0.17.0` | 保留（真实值） |

- **UX**：菜单变成 iOS 设置那样的一列导航；摘要从"这页有什么"变成"我现在是什么"。
- **DX**：`summary()` 从 8 个 case 缩到 6 行，**且不再复制子页状态**。原先"背景"那格要同时知道 `prefs.background.path` 与 `prefs.monet.enabled`，任何一边改了摘要就会撒谎——现在摘要与子页读同一个源。
- **AX**：每个菜单项的可访问名从「阅读 + 衬线 18px · 1.75 倍」缩到「阅读 + 衬线 18px」。agent 要判断"字号现在多少"时，少读 3 个词。

### 1.3 作用域写进按钮文案，删掉消歧提示句（1 处）

设置子页底部有页级「恢复全部」，分组标题旁有组级「恢复默认」，两个同名不同域，于是页面底部挂了一句：

> 只影响「阅读」页；单个分组可在标题右侧单独恢复

这是**典型的"靠文案撑起来的复杂度"**：句子的存在是因为控件本身没说清自己管多大范围。

- **改布局**：页级按钮文案改成 **「恢复本页默认」**，提示句整段删除。
  作用域写进控件本身，不再需要旁边的句子解释；组级按钮仍叫「恢复默认」（它贴着组标题，作用域显然）。
- **功能零损失**：页级恢复仍然重置该页全部可回退项，与改动前完全一致。
- **UX / AX**：两个按钮不再同名，歧义从根上消失；agent 读到的可访问名 `恢复本页默认` 自带作用域。

---

### 1.4 空状态：删掉说明句（4 处）

| 现状标题 | 现状说明 | 处置 |
|---|---|---|
| 书架还是空的 | 导入本地文件，或拖拽文件夹到这里 | 删说明句 |
| 没有找到匹配的书 | 试试其他关键词。 | 删说明句 |
| 这个分类还没有书 | 切换到"全部"查看。 | 删说明句 |

- **改布局**：空状态 = 插画 / 图标 + 一行标题 + 按钮。三个按钮（导入文件 / 导入文件夹 / 清空搜索 / 查看全部）已经说清了要做什么，说明句是复述。
- **UX**：少一层文字，多一层留白。
- **DX**：删掉 `desc` 变量与 4 个分支，以及 `.empty-desc` 样式。
- **AX**：「切换到"全部"查看。」这种句子对 agent 是纯噪声——按钮标签已经给了可执行动作。

**保留**：书架插画 `ShelfArt`。它是插画不是标语，承担"这里该放书"的引导；删掉属于视觉方向的改变，不在本轮"砍标语/提示/次要标签"范围内。

---

### 1.5 卡片与列表：删掉"类别"（2 处）

`categoryOf()` 的实现是**纯从 `format` 推导**的：

```
pdf → pdf；漫画格式或 comic 类型 → comic；文档格式或 doc 类型 → doc；
电子书格式 → ebook；其余 → text
```

所以**「类别」列和「类型」列是同一个输入的粗细两种写法**，信息量完全被后者包含。

- 网格视图：元信息行从 `EPUB · 沈砚 · 电子书` → `EPUB · 沈砚`（删分类名）
- 列表视图：删掉整列「类别」，6 列 → 5 列（封面 / 标题 / 类型 / 进度 / 最近阅读）

- **UX**：网格每张卡少一个词；列表少一整列，行宽立刻松了。
- **DX**：`metaLine()` 失去分类参数后退化成"取作者名"，整个函数连同它的去重规则一起删掉——它存在的唯一理由就是拼三个来源。
- **AX**：分类可由格式推导，agent 读列表时少读一整列 N 个词（12 本书 = 12 个词），且不会把"类别=PDF"与"类型=EPUB"这种矛盾读出来。
- **零信息损失**：侧栏的分类计数与筛选仍然提供分类维度。

---

### 1.6 搜索框角标（1 处）

- `Ctrl F` 角标删除。快捷键在设置 → 快捷键里有完整列表；搜索框是输入区不是命令区。
- **DX**：删掉 `.search-kbd` 与它的 3 条配套规则（含一条 `@media` 内的），样式表不留孤儿。
- **AX**：agent 读搜索框时少一个假控件——`Ctrl F` 是快捷键提示，不是可操作的东西。

---

### 1.7 拖拽投放层说明句（1 处）

- `电子书文件或整个文件夹都可以` 删除，保留主指令 `松开即可导入`。
- **UX**：投放层只留一句话。
- **DX**：删 `.drop-desc` 样式。

---

### 1.8 私密书架弹窗：删掉与设置页重复的说明（1 处）

`PrivateShelf` 弹窗底部写着：

> 这一版只做「看不见」：书还在磁盘上，标题也还是文件名。真要防懂电脑的人，得等加密那一版。

而 `PrivacySettings.tsx` 里**已经有一份同样的说明**（且更完整）。两处说同一件事 = 两处可能互相矛盾（D1）。

- **处置**：弹窗里删掉，设置页那份保留（解释功能边界属于设置页的职责）。
- **UX**：弹窗从 4 段缩到标题 + 一行状态 + 按钮。
- **DX / AX**：重复文本消除，agent 不会在两处读到措辞不同的同一句话。

## 2. 明确不砍的

砍减法最怕砍过头。以下几项经评估**保留**：

| 保留项 | 理由 |
|---|---|
| 关于页的格式清单 | 数据表不是标语，删了是真实信息损失 |
| 书架插画 `ShelfArt` | 插画承担引导，不是文案 |
| 卡片的格式标签 | 刚在 v0.17.2 从封面移下来，是识别文件类型的唯一可见信息；作者是可选项，没有作者时元信息行只剩格式，不会空 |
| 顶栏 tooltip（`data-tip`） | 悬停才出现，不占静止态视觉预算；且它们承载快捷键与作用说明，是 affordance 不是标语 |
| 列表视图的「最近阅读」列 | 真实状态，不是预告 |
| 阅读页工具栏 / 目录 / 快捷键帮助 | 阅读层的"克制"已经做到了，不在本轮范围 |
| 对话框里的后果说明（删除确认、恢复默认确认） | 这是**不可逆操作的后果告知**，不是界面自述。砍掉会造成真实的信息损失 |
