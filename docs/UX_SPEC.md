1. UX 原则

1. 一本书一个入口：用户不关心底层是哪个渲染引擎。书架、进度、继续阅读、返回行为对三种格式完全一致；格式差异只体现在阅读区内部的翻页与缩放。
2. 不打断阅读：阅读中的一切反馈（保存进度、预加载、缓存）必须静默；只有失败且影响继续阅读时才提示。
3. 先给结果，再给过程：打开书先出内容骨架，再填内容；导入先入书架（占位），再补封面与元数据。禁止用整页转圈阻塞。
4. 可撤销则不确认，不可撤销则必须确认：从书架移除（保留文件）用 Toast 撤销；删除本地文件、清空进度若不可恢复才用对话框。清空阅读进度可撤销，因此用 Toast 撤销，不用对话框。
5. 键盘全流程可达：不用鼠标也能完成导入、搜索、打开、翻页、退出、删除。任何依赖悬停才能发现的功能，必须有键盘等价物。
6. 错误说人话，给下一步：文案包含“发生了什么 + 你可以做什么”，不暴露堆栈、错误码、引擎名。
7. 状态可预期：同一操作在任何格式、任何主题下行为一致；不一致必须有可见理由（如日漫 RTL 反转）。

2. 用户与核心任务

2.1 目标用户

· 本地存有大量 TXT / EPUB / CBZ / PDF，分散在多个文件夹。
· 同时读小说与漫画，偶尔看扫描版 PDF。
· 桌面端长时间使用，偏好键盘，夜间阅读比例高。
· 不需要在线书源、社交、云同步（P1 明确不做）。

2.2 核心任务（按优先级）

优先级 任务 成功标准
T1 把本地文件导入书架 拖拽或选择后 3 秒内出现在书架，可立即打开
T2 找到上次读的书并继续 从启动到继续阅读 ≤ 3 次点击 / 1 次快捷键
T3 沉浸阅读并翻页 翻页无闪烁、无跳变，进度自动保存
T4 在三种格式间切换阅读 不需要学习第二套操作
T5 管理书架（搜索、筛选、移除） 搜索 200ms 内出结果；移除不误删文件
T6 调整阅读设置 即时生效，不中断阅读

2.3 非目标（P1 不做）

在线书源、RSS、云同步、TTS、批注（高亮与笔记）、多选批量操作、阅读统计、插件、标签。

> v1.3 修正：**书签与书内搜索已实现**（0.16.0 / 0.18.0），从本清单移除，交互见 §17。
> 其余各项仍不得出现在 P1 的任何入口中（包括置灰按钮、侧栏筛选项、顶栏按钮）。

顶栏顺序（v1.3 实测）：返回 · 书名 · 目录 · **书签** · **书内搜索** · 快捷键 · 设置。
书签与搜索都插在「目录」与「设置」之间，与本文 v1.2 预留的位置一致；侧栏仍不含「标签」筛选项（未实现）。

3. 信息架构与导航

3.1 层级模型

```
应用
├── 书架（默认首页）
│   ├── 侧栏筛选：全部 / 小说 / 漫画 / PDF / 最近阅读
│   ├── 搜索
│   └── 书籍详情（轻量，右键或卡片菜单触发，非独立页）
├── 阅读页（书籍上下文内）
│   ├── 目录抽屉
│   └── 设置抽屉（含「关于」分组）
└── 全局：导入
```

关于入口：不设独立「关于」页面或对话框；「关于」是设置抽屉的最后一个分组。设置抽屉是唯一的全局设置入口。

3.2 导航规则

· 必须：书架是唯一首页，应用启动即进入书架，不设启动页/欢迎页。
· 必须：阅读页是书架的子层级，不是并列页。返回（Ctrl/Cmd + B、顶栏返回、Esc 栈末位）回到书架并恢复原滚动位置与筛选状态。
· 必须：目录与设置是抽屉，不跳转页面，不卸载阅读区。
· 禁止：P1 出现三级以上页面嵌套；禁止模态框里再开模态框。
· 应当：从书架打开书时，保留书架 DOM 状态（虚拟滚动位置、搜索词），返回时零等待。

3.3 启动行为

场景 行为
首次启动（书架为空） 直接显示书架空状态 + 导入引导，不弹多步向导
非首次启动 显示书架，恢复上次筛选与滚动位置；不自动打开上次的书
带文件参数启动（文件关联） 直接打开该书阅读页；书架在后台就绪，返回可用；文件丢失/损坏按 §5.3 处理
上次异常退出 书架正常显示；打开书时按 §5.3 恢复进度

多窗口：P1 单窗口。禁止依赖 Tauri 默认多窗口行为；打开文件关联时复用当前窗口。

4. 全局心智模型

4.1 统一进度的语义

对用户只暴露一个进度概念：

· 书架卡片：百分比 + 细条（视觉见 UI 规范 §5.4）。
· 阅读页底栏：百分比 + 位置描述（小说“第 3 章 · 42%”，漫画/PDF“第 45 / 210 页”）。
· 禁止在同一界面混用“章”“页”“位置”三种计量而不加限定。

标点分工（v1.2 明确）：视觉呈现用间隔点「第 3 章 · 42%」，屏幕阅读器播报用逗号「第 3 章，42%」。两者不是笔误，分别服务扫读节奏与语音断句，实现时按场景各取其一。

4.2 格式差异的暴露边界

差异 是否暴露给用户 方式
翻页方向（日漫 RTL） 暴露 首次进入该格式阅读时，底栏显示一次性提示「日漫模式：← 下一页」，3 秒消失（与 Toast 时长一致），设置可关
单/双页 暴露 底栏按钮 + 快捷键 D（UI 规范 §6.3 / §7.1）
缩放能力 暴露 底栏缩放控件，仅漫画/PDF 显示
渲染引擎、解压方式、编码 禁止暴露 不出现在任何 UI 文案中
PDF 模式（翻页/滚动） 部分暴露 自动切换时底栏短暂提示；锁定按钮常驻

v1.2 修正：方向提示原写 5 秒，与 Toast 3 秒规则冲突；现统一 3 秒，走 Toast 组件，不自造长驻提示。

4.3 状态记忆

必须跨会话记忆：

· 应用主题、阅读主题、字号/行高/页宽、阅读方向、单双页偏好、PDF 模式锁定、侧栏折叠、书架视图（网格/列表）、排序方式、最近筛选。
· 同一会话内，从阅读页返回书架时恢复原滚动位置与筛选状态。

应当跨会话记忆：

· 书架滚动位置（按筛选分别记忆）。
· 窗口尺寸与位置。

禁止记忆：

· 临时 Toast、抽屉开合、工具栏显隐（每次进入阅读页都从隐藏开始）。

5. 关键流程

5.1 首次启动

```
启动 → 书架空状态
  ├─ 主按钮「导入文件」→ 系统文件选择器（多选）
  ├─ 次按钮「导入文件夹」→ 系统文件夹选择器（递归扫描）
  └─ 拖拽区域提示：可直接把文件/文件夹拖到窗口
```

· 必须：空状态同时支持点击导入与拖拽导入，两者结果一致。
· 必须：首次启动不要求用户先设置任何偏好；所有设置项有合理默认值。
· 应当：空状态说明支持格式（TXT / EPUB / CBZ / 图片文件夹 / PDF），一行内说完，不展开技术细节。

5.2 导入流程

```
触发导入
  → 立即在书架插入占位卡片（标题=文件名，封面=格式占位图，状态=处理中）
  → 后台逐个解析：编码探测 / 元数据 / 封面 / 页数
  → 成功：占位卡片原地替换为正式卡片，淡入
  → 失败：占位卡片转为错误态，可点击查看原因
  → 全部结束：Toast 汇总「导入完成：成功 N，失败 M，跳过 K」
```

必须遵守：

1. 不阻塞：导入期间书架可滚动、可打开其他书、可继续导入。
2. 逐条失败隔离：单个文件失败不影响其余文件。
3. 去重判定：路径 + 文件大小 + 修改时间。命中时默认跳过，并在汇总里报告“已存在 N 个，已跳过”；提供“查看并处理”入口，可改为“保留两份”。保留两份时以内部 ID 区分，去重键不再包含路径。
4. 文件夹递归：支持嵌套目录；不跟随符号链接；递归深度上限 8 层；跳过隐藏文件与系统文件；空文件夹不报错。
5. 拖拽目标：窗口任意位置可接收拖拽，拖入时显示全窗口投放提示层；拖拽离开窗口即取消，不导入。
6. 大文件：单文件 > 50MB 时占位卡片显示解析进度（不确定进度用脉冲条），不弹窗。
7. 可取消：批量导入时 Toast 常驻显示“取消”按钮；取消只停止未开始的任务，已完成的保留。
8. 失败可查看：失败卡片点击显示原因与「重试」「从书架移除」。失败原因统一为：权限不足 / 格式不支持 / 文件内容无法识别 / 文件已损坏。

图片文件夹识别规则：

· 一个被导入的图片文件夹默认对应一本漫画，只取该文件夹第一层的直接图片文件。
· 子文件夹不自动合并到父文件夹；用户导入的文件夹内部第一层子文件夹若每个都含图片，则每个子文件夹作为独立漫画导入；若子文件夹内无图片，忽略。
· 父目录自带图片且同时含包子文件夹（v1.2 补充）：两者分别成为独立书籍——父目录一本（仅第一层直接图片），每个含图的子目录各一本。不得出现「父目录的书包含子目录图片」或「子目录图片被父目录吞掉而丢失」两种结果。
· 图片按自然数文件名排序（1, 2, 10 而非 1, 10, 2）；无法自然排序时按文件名字典序，并在书籍详情中提供“手动排序”入口（P2）。
· 支持扩展名白名单：.jpg / .jpeg / .png / .webp / .gif / .bmp / .avif。其他文件忽略，不报错。
· 单本漫画图片数 > 5000 时，导入完成但书架卡片角标提示“页数较多”，不阻塞。

禁止：

· 导入期间弹出阻塞式进度对话框。
· 导入完成后自动跳转到某本书。
· 对不支持格式静默忽略（必须出现在失败汇总里）。

5.3 打开书籍与进度恢复

```
点击书籍 / 按 Enter
  → 立即切换到阅读页（不等文件完全加载）
  → 阅读区显示骨架屏（按格式给不同骨架：文字行 / 图片块 / PDF 页框）
  → 定位到上次阅读位置
  → 内容就绪后淡入，骨架移除
```

进度恢复规则：

情况 行为
有有效进度 直接定位，无提示
进度无效（文件变短、章节消失） 回退到最近有效位置；Toast「未能恢复上次进度，已回到最近的可用位置」
无进度（首次打开） 从头开始，无提示
文件已丢失 不进入阅读页，弹对话框「文件已丢失」+「重新定位」「从书架移除」
文件损坏 不进入阅读页，弹对话框「文件可能已损坏，无法解析」+「重新定位」「从书架移除」
文件内容无法识别 不进阅读页，卡片错误态 +「重试」「从书架移除」

v1.2 修正：文件损坏原为「进入阅读页但显示错误态」，与 UI 规范 §10.2「打开时对话框」冲突。现按 UI 为准：损坏文件无法计算位置，进阅读页只会得到一片空壳，对话框更快给到下一步。

必须：

· 打开操作的感知延迟：骨架屏 300ms 内出现；超过 2 秒未就绪，骨架屏下方显示“正在加载…”文字（非转圈）。
· 切换书籍时释放上一本书的渲染资源（canvas、图片缓存、worker），不累积内存。
· 返回书架时恢复原滚动位置，零等待（书架 DOM 不卸载）。

5.4 阅读中的交互

翻页与工具（数值见 UI 规范 §6.2）：

· 点击左 25% / 右 25% 翻页，中央 50% 切换工具栏。
· 必须区分“点击”与“选择”：mousedown 后指针移动 > 8px 视为文本选择，不触发翻页与工具栏切换。
· 必须：双击选词、三击选段不触发翻页。判定期间（首次 mousedown 后 250ms 内）延迟执行点击行为；若判定为多击，取消点击行为。文本选择期间（selection 非空）抑制点击热区行为。
· 必须：触控板双指滚动、鼠标滚轮在翻页模式下不翻页（仅滚动模式生效），避免误触。
· 必须：翻页后新页内容在首个绘制帧内可见（不得出现空白页）；位移动画沿用 --dur-page 160ms，动画时长不等于内容可见时限。

进度保存（全文档唯一表述）：

阅读位置发生变化后启动 500ms 防抖计时；计时期间再次发生位置变化，则重新计时。停止变化 500ms 后写入数据库。退出阅读页、切换书籍、关闭窗口时立即写入。进度条拖动期间暂停防抖写入，松手后立即写入。

崩溃或强杀时，丢失范围以最后一次成功落盘为准，最多为最近一个防抖窗口（500ms）内的进度；快速连续翻页时可能丢失多页，实现不得以「只丢 1 页」为前提做假设，也不得因此缩短防抖时间换取写盘频率。

v1.2 修正：原文「最多丢失 1 页」与 500ms 防抖机制不相容——防抖期间连续翻 5 页崩机就是丢 5 页。现改为按防抖窗口描述，并明确禁止实现侧假定「1 页」。

工具栏（显隐规则见 UI 规范 §4.3）：

· 必须：进入阅读页时工具栏为隐藏状态，正文无任何常驻控件遮挡。
· 必须：工具栏显示/隐藏不引起正文重排（overlay，不挤压内容）。
· 必须：工具栏隐藏后，键盘用户仍可通过 F6 / Tab 唤出（见 §8）。

目录：

· 打开目录抽屉时不暂停阅读区滚动位置的记忆；关闭后回到原位置。
· 点击目录项跳转后，抽屉保持打开（便于连续跳转），用户手动关闭或按 Esc。
· 当前章节高亮必须随阅读位置实时更新。
· 目录抽屉内搜索框聚焦时，Esc 先清空搜索并保持抽屉打开；再次 Esc 关闭抽屉。

设置：

· 所有设置即时生效，无保存按钮。
· 字号/行高/页宽调整时，正文保持当前阅读位置（按锚点重排），不得跳回章首。
· 主题切换不闪烁：先切换容器背景，再切换内容颜色，间隔 ≤ 1 帧。

5.5 退出与关闭

场景 行为
Esc 按 UI 规范 §7.2 优先级栈消费；栈末位退出沉浸并返回书架，不重复展开
关闭窗口（无进行中任务） 立即写入进度后关闭，无确认
关闭窗口（导入进行中） 对话框「导入尚未完成，关闭将中断」+「继续导入」「仍然关闭」
关闭窗口（阅读中） 无确认，静默保存

禁止：阅读器在关闭时弹“是否保存进度”——进度必须自动保存。

6. 书架交互

6.1 浏览

· 必须：默认网格视图；视图切换按钮在顶栏右侧，状态跨会话记忆。
· 必须：卡片悬停显示“继续阅读”浮层，点击浮层与点击卡片行为一致（打开并恢复进度）。
· 必须：右键菜单分组见 §10.1；键盘 Shift+F10 或菜单键可唤出。
· 应当：卡片支持键盘导航（方向键在网格中移动焦点，Enter 打开）；首尾卡片焦点循环到另一端。
· 禁止：悬停才显示的信息（如完整标题、进度）无法通过键盘获取；必须有 Tooltip 或 aria-label 等价物。

6.2 搜索

```
Ctrl/Cmd+F → 聚焦搜索框（preventDefault）
  → 输入 → 200ms 防抖 → 即时过滤
  → 无结果 → 空状态「没有找到匹配的书」
  → Esc → 清空并退出搜索，焦点回到书架
```

· 必须：搜索匹配标题与作者，不区分大小写，支持中文子串。
· 必须：搜索时保持当前筛选（如“只看漫画”内搜索）。
· 应当：搜索词高亮命中片段（P1 可仅高亮标题）。
· 应当：作者为空的书籍只按标题匹配；标题重复时按最近阅读时间排序。

6.3 筛选与排序

· 侧栏筛选：全部 / 小说 / 漫画 / PDF / 最近阅读。必须显示各分类计数。P1 不含「标签」。
· 排序（P1）：最近打开 / 添加时间 / 标题。默认最近打开。标题排序支持中文拼音排序。
  （排序项原名「最近阅读」，与侧栏筛选项「最近阅读」同名不同义，已改名消歧。）
· 必须：筛选与排序状态跨会话记忆；从阅读页返回时保持。

6.4 移除与删除

见 §10。书架内不提供“清空书架”一键操作。

7. 阅读交互（三格式）

本节只写行为，视觉与数值见 UI 规范 §6。

7.1 小说（TXT / EPUB）

· 默认分页；可切纵向滚动，切换时保持当前阅读位置。
· 字号/行距/页宽调整后按文本锚点重排，不跳章。
· EPUB 目录层级完整呈现；无目录时显示“本书无目录”，不隐藏抽屉入口。
· TXT 章节切分失败时，降级为“按比例定位”（百分比），底栏显示“位置 42%”，不显示章节名。
· 必须：文本选择支持复制（Ctrl/Cmd+C），选择期间不翻页。

7.2 漫画（CBZ / 图片文件夹）

· 默认日漫 RTL 单页；首次进入该格式给一次性方向提示（见 §4.2）。
· 双页模式按 UI 规范 §6.3 配对；跨页拼接不出现中缝错位。
· 条漫模式：左右点击/方向键滚动 80% 视口，平滑滚动；中央点击切换工具栏。
· 必须：预加载前后各 3 页；快速连续翻页时，未就绪页显示骨架而非上一页残影。
· 必须：图片解码失败显示单页占位 + 重试，不影响其他页。

翻页按键映射：

输入 日漫（RTL） 西漫 / PDF（LTR）
点击左侧 25% 下一页 上一页
点击右侧 25% 上一页 下一页
← 下一页 上一页
→ 上一页 下一页
Space / J 下一页（逻辑） 下一页（逻辑）
Shift+Space / K 上一页（逻辑） 上一页（逻辑）
D 切换单页/双页 切换单页/双页

规则：←/→ 是物理方向，日漫反转；Space/J/K 是逻辑翻页，不反转。RTL 模式下进度条不反向。

7.3 PDF

· 默认单页翻页；缩放 > 110% 自动切连续滚动，< 95% 切回；工具栏可锁定模式（UI 规范 §6.5）。
· 大文件按可视区域渲染；滚动时未渲染页显示页框骨架，不显示空白。
· 单页渲染失败：该页显示占位 + 重试，其余页正常。
· 必须：横向页面自动适合宽度；旋转按钮每次 90°，旋转后保持当前页。
· 禁止：整本 PDF 一次性渲染所有页。

模式切换防抖：

· 自动切换阈值：缩放 > 110% 切连续滚动，< 95% 切回翻页；避免 100% 附近反复跳变。
· 用户手动锁定模式后，自动切换完全停止，直到用户解除锁定。
· 切换模式后保持当前页和阅读位置；连续滚动切回翻页时，定位到当前可视区域顶部页。

v1.2：本节的 110%/95% 已被 UI 规范 v1.3 §6.5 采纳为唯一阈值，冲突消除。

7.4 三格式共同约束

· 返回书架、打开目录、打开设置、Esc 栈、进度条位置与拖动行为完全一致。
· 翻页快捷键语义一致：←/→ 物理方向（日漫反转），Space/J/K 逻辑翻页（不反转）。
· 任何格式下，阅读位置变化后 500ms 防抖后写入数据库（§5.4 统一表述）。

8. 键盘与焦点

8.1 焦点模型

· 必须：进入阅读页后，焦点落在正文容器（tabindex="-1"），而非某个按钮。
· 必须：Tab 首次从正文进入顶栏，F6 在顶栏/底栏间循环，Esc 按栈退出（UI 规范 §7.2）。
· 必须：工具栏因 Esc 隐藏前，焦点先移回正文容器，焦点不得掉到 body。
· 必须：焦点环始终可见（UI 规范 §5.1），禁止 outline: none 无替代。
· 必须：焦点顺序符合视觉顺序；抽屉打开时焦点陷阱在抽屉内，关闭后回到触发元素。

8.2 键盘全流程验收路径

以下路径必须仅用键盘完成：

1. 启动 → Tab 到“导入文件” → Enter → 选择文件 → 回到书架。
2. Ctrl/Cmd+F → 输入 → ↓ 选中结果 → Enter 打开。
3. 阅读中 ← / → / Space 翻页，T 开目录，↑↓ 选择，Enter 跳转，Esc 关抽屉。
4. Ctrl/Cmd+, 开设置，Tab 遍历，调整字号，Esc 关闭。
5. Esc 退出沉浸 → 书架 → Shift+F10 打开右键菜单 → 选择“从书架移除”。

8.3 快捷键原则

· 输入框聚焦时，除 Esc 外不响应全局快捷键。
· Ctrl/Cmd+F 必须 preventDefault()（UI 规范 §5.3）。
· 阅读页 Ctrl/Cmd+F：P1 阅读页不提供全文搜索；按下后返回书架并聚焦搜索框（复用 Ctrl/Cmd+B 逻辑 + 聚焦搜索）。不弹 Toast，不静默无响应。
· 所有快捷键在设置页可查看；P2 支持自定义。
· 禁止使用单字母快捷键执行破坏性操作。

8.4 Esc 优先级表

优先级 当前状态 Esc 行为
1 模态对话框打开 关闭对话框（危险确认框按按钮规则处理）
2 抽屉打开（目录/设置） 关闭抽屉；若抽屉内搜索框聚焦，先清空搜索
3 工具栏可见 焦点移回正文容器 → 隐藏工具栏
4 全屏中 退出全屏
5 沉浸阅读中 退出沉浸，返回书架
6 书架页面 不执行操作

多个状态同时存在时，按优先级从高到低消费，一次 Esc 只触发一层。禁止多个组件各自监听 Esc 导致一次按键触发多个动作。

10. 文件安全与可撤销

10.1 两种移除与右键菜单分组

操作 语义 菜单分组 确认方式
从书架移除 只删记录与缓存，保留文件 移除组（分隔线之后） 无需对话框，Toast 提供“撤销”（5 秒）
删除本地文件 删文件 + 记录 + 缓存 移除组（分隔线之后） 必须二次确认，显示文件名与完整路径

右键菜单固定顺序：

```
打开
在文件夹中显示
编辑信息
───────────（分隔线）
从书架移除
删除本地文件
```

文件操作组与移除组之间必须有分隔线；「删除本地文件」必须是 Danger 项。

10.2 删除事务一致性

执行顺序与补偿：

1. 移动文件到回收站。
2. 删除数据库记录。
3. 删除缓存。

步骤结果 处理
步骤 1 失败 不删除记录；Toast 错误；书架状态不变
步骤 1 成功、步骤 2 失败 尝试将文件从回收站恢复到原位置；恢复成功则书架不变；恢复失败则保留记录并标记为“待恢复”状态，右键提供「重新定位」「移除记录」
步骤 1、2 成功、步骤 3 失败 记录已删，缓存残留不影响正确性；后台清理，不提示
全部成功 书架移除卡片

必须：

· 优先移入系统回收站；不支持回收站时，确认对话框明确写“将永久删除”。
· 删除失败后，书架记录与文件状态必须一致，不出现“记录没了文件还在”或反之。
· 「待恢复」是可见状态：卡片角标 + 右键入口，视觉规范见 UI §5.4 卡片异常态，工具用 --c-warning，与「文件已丢失」（--c-text-tertiary）区分。
· 确认按钮文案是动作本身（“删除本地文件”），不是“确定”。
· 禁止：任何形式的“清空书架并删除全部文件”一键操作。

10.3 可撤销范围

操作 可撤销 方式
从书架移除 是 Toast 5 秒内“撤销”
清空阅读进度 是 Toast 5 秒内“撤销”（可恢复，不用对话框；UI §5.8 已明确）
删除本地文件 否（进回收站可手动恢复） 二次确认
修改书籍信息（P2） 是 Toast 撤销

12. 性能感知

必须：

· 书架首屏骨架 300ms 内出现；封面异步加载，完成淡入 120ms（UI 规范 §9）。1000 本以上大书库放宽到 500ms（见验收）。
· 打开书籍骨架 300ms 内出现；超过 2 秒显示“正在加载…”。
· 翻页在预加载命中时，新页首帧即绘制（≤1 帧）；视觉过渡 160ms 内完成。
· 导入不阻塞 UI；批量导入显示非阻塞进度条。
· 切换书籍释放上一本资源；连续打开 10 本书内存不持续增长（验收方式：DevTools Memory 快照，打开 10 本后堆内存回落到基线 ±10% 内）。
· 搜索 200ms 防抖，输入过程中不阻塞。
· 1000 本书库场景：冷启动书架首屏骨架 ≤ 500ms；搜索输入到结果 ≤ 300ms。

v1.2 修正：原 §12 只写「300ms 内」，验收写「1000 本 ≤500ms」，两者被读成矛盾。现明确 300ms 是常规量级目标，500ms 是大书库上限，验收按书库规模择一适用。

禁止：

· 整页转圈加载。
· 滚动时出现空白页（PDF/漫画）。
· 因后台任务导致翻页掉帧。

13. 可访问性

· 必须：所有功能键盘可达（§8.2 路径全通过）。
· 必须：所有图标按钮有 aria-label；图片型内容有页码/进度文本供屏幕阅读器播报。
· 必须：翻页时 aria-live="polite" 播报位置变化，节流 500ms，避免连续翻页刷屏。播报格式：「第 45 页，共 210 页」；小说为「第 3 章，42%」（播报用逗号，视觉用间隔点，见 §4.1）。
· 必须：不依赖颜色单独传达状态（错误同时有图标/文案）。
· 必须：prefers-reduced-motion 下：翻页瞬时、抽屉无动画、Skeleton 静止、卡片淡入禁用、悬停过渡禁用、主题切换无颜色渐变、页面切换无位移。
· 必须：正文对比度 ≥ 7:1，UI 文本 ≥ 4.5:1（UI 规范 §8）。
· 应当：支持系统字体缩放（rem 基准），UI 不因放大而截断。

14. 文案规范

· 语言：简体中文；标点用中文标点；省略号用 …。
· 按钮：动词开头，2–4 字（“导入文件”“重新定位”“从书架移除”）。
· 危险按钮：写动作本身（“删除本地文件”），不用“确定”。
· 数字：阿拉伯数字；页码写“第 45 / 210 页”；百分比写“42%”。
· 语气：中性、简洁、不责备、不卖萌、不用感叹号。
· 技术词：不出现“解析器”“渲染引擎”“编码”“解压”；用“文件”“格式”“加载”“内容无法识别”。
· 长度：Toast ≤ 30 字；对话框说明 ≤ 60 字；空状态说明 ≤ 40 字。

17. 书签与书内搜索（v1.3 补记，已实现）

本章记录 0.16.0–0.18.5 落地的两件事，供后续修改时对照。视觉见 UI 规范，本节只写行为。

17.1 入口

· 阅读页顶栏固定两个按钮：书签（打开面板，停在「书签」页签）、书内搜索（打开面板，停在「搜索」页签）。
· 面板与目录抽屉同一套外壳：同一侧、同宽、同样的头高与滚动手感；Esc 的优先级高于目录抽屉，低于设置。
· 六种阅读器（TXT 族 / HTML 族 / EPUB / PDF / 漫画 / OFD）行为一致，只有搜索可用性不同。

17.2 书签

· 加：面板顶部「在当前位置加书签」，默认备注取「第 N 章 · 42%」。
· 管理：逐条可重命名（行内编辑，回车保存、Esc 放弃、清空恢复默认）、删除、跳转。
· 排序：书签多于一条时提供「按位置 / 按时间」，默认按位置。位置序由各阅读器提供——文本按字节偏移、翻页按页码、EPUB 按「章节序号 × 1000 + 章内比例」。
· 去重：同一位置重复添加不生成新条目，提示「这个位置已有书签」。容差：文本 0.2%、翻页同页码、EPUB 章内 1%。
· 删除可撤销：6 秒内可恢复。撤销是重新插入，因此拿到新的 id 与时间，位置与备注不变。
· 位置与进度的关系：书签存的就是 `Progress`，与「续读」同一坐标，跳回必然落在原处。

17.3 书内搜索

· 覆盖 11 种格式：TXT / MOBI / AZW3 / FB2 / RTF / MHTML 扫正文；HTML / MD / DOCX / XLSX 扫 HTML（剥标签时保持字节偏移）；EPUB 逐章扫。PDF 自 0.21 起走 pdf.js 文字层（见 §18.7）；漫画与 OFD 无文字层，入口保留但提示不支持。
· 命中上限 200 条，满即停；结果按章节顺序给出「章节名 + 上下文」，命中词高亮，点击跳转。
· 精度边界：EPUB 的 `progression` 用「命中处字符数 / 全章字符数」近似，而阅读器里的 progression 是滚动比例，落在附近而非精确到行。

17.4 窄窗信息降级

· < 768px：侧栏收起为图标列，条目纵向堆叠「图标在上、数量在下」；顶栏「导入」降为 32×32 图标按钮；搜索占位符按可用宽度切换短文案。
· 列表视图 < 768px：隐藏「类别」列，进度百分比并入书名行末尾右对齐。
· 设置抽屉窄屏：字段说明允许换行，不再单行截断；「关于」页的「标签 + 说明」改为两行（标签与箭头一行、说明另起）。

17.5 自绘菜单的键盘行为

· 分类筛选、排序、视图切换都是自绘菜单，不使用原生 `<select>`。
· 打开后焦点进入菜单；↑↓ 移动、Enter 选中、Esc 关闭并把焦点还给触发按钮。
· 触屏不依赖悬停：菜单项高度 ≥ 40px，点击区域覆盖整行。

18. 标注与脚注（v1.4 补记，已实现）

本章记录 0.21 落地的三件事：划词高亮 / 笔记、标注的导出与回导、脚注就地弹窗。
书签部分仍见 §17.2，行为未变；面板从「书签 / 搜索」两页签改为「标注 / 搜索」。

18.1 入口与面板

· 阅读页顶栏原「书签」按钮改名为「标注」（`aria-label` 与 `title` 同步），打开的面板里混合显示书签 / 高亮 / 笔记三类。
· 面板顶部保留「在当前位置加书签」——它是唯一不依赖选区的添加方式，不能因为有了划词就撤掉。
· 条目多于一条时出现类型筛选（全部 / 书签 / 高亮 / 笔记，只显示有条目的类型）与「按位置 / 按时间」排序；筛选与排序可叠加。
· 每行左侧有类型徽标（书签 / 高亮 / 笔记），徽标只作识别，不可点击。
· 面板右上角两个图标按钮：导入（仅桌面端）、导出。

18.2 划词高亮与笔记

· 触发：在正文里选中文字后，浮条出现在选区旁，两个动作——「高亮」一键完成、「笔记」展开输入框。
· 浮条位置：桌面端优先放在选区上方（越界翻到下方）；触屏端优先放在下方，避开系统自带的选词菜单。
· 选区快照：选中那一刻就算好并冻结（章内起点、长度、原文、位置矩形），之后浏览器把选区交还给输入框或收起，都不影响落库。
· 空白处理：选区首尾空白不计入；跨段选择按段落切开绘制，段落行尾的换行符不参与着色。
· 视觉区分：高亮是正文下方一条荧光带；笔记是另一色带子加虚线下划线。两者都不改变文字颜色。
· 点划线：不翻页，弹提示条念出这条标注的备注；没有备注则提示「已划线」。
· 覆盖范围：TXT / HTML / EPUB。PDF、漫画、OFD 没有可选择的连续文本，不提供划词。

18.3 坐标语义与失效

· 高亮存「章内字符区间」（`anchor.start` / `anchor.len`，UTF-16 码元，半开区间），章身份来自 `locator`（TXT 章节序号 / EPUB href）。
· 因此改字号、行高、字体、分页与滚动模式都不会让划线漂移；书本身换了内容才可能偏。
· 绘制前用保存的原文校验区间内容，对不上就**不画**——不提示、不报错，宁可少一条也不画到别的句子上。
· 同一区间重复创建不拦（用户可能真的想再标一次），但列表里不会自动合并。

18.4 笔记编辑

· 行内多行编辑：点击铅笔进入，`Ctrl/⌘ + Enter` 保存，Esc 放弃；失焦也保存。
· 笔记正文上限 2000 字，书签备注上限 60 字。
· 删除可撤销（6 秒），撤销时**原样恢复类型、锚点、原文与备注**——只恢复备注而不恢复锚点，划线就消失了。

18.5 导出与回导

· 导出三种格式，由保存对话框里的扩展名决定：`.md`（给人看）、`.csv`（表格）、`.json`（可回导）。
· Markdown 的引用块固定表示「书里原话」，普通段落表示「我写的」；书签的备注是引用块。
· CSV 在位置列之后附带 `anchor_start` / `anchor_len`，书签这两列为空而不是 0。
· 回导只接受 `.json`：文件头带 `format` 与 `version`，认不出或版本更高都直接拒绝并说明原因。
· 去重键 = 类型 + 位置 + 锚点 + 备注 + 原文，五项全同视为同一条；同一份文件导入两次不会新增条目。
· 结果反馈为「导入 N 条，跳过 M 条」，文件里的书名与当前书不同时附一句提示，但不阻止导入。
· 导入与导出都只在桌面端提供：移动端没有可用的系统文件对话框。

18.6 脚注就地弹窗

· 触发：点击正文里的引用标记。判据三条任一成立——`epub:type` / `role` 含 note；目标 id / class 含 fn / note / footnote；链接文字是纯编号（`1`、`[2]`、`①`、`iv`）。
· 判不出来就按普通链接跳转：宁愿多按一下，也不把「第 3 章」这类章内链接误弹成脚注。
· 内容：目标元素的文字，去首尾空白、削掉末尾的「返回 / 回到正文」标记；超过 1200 字符不弹窗（那是跳转不是注释）。
· 本章内隐藏的注释（`display:none`）也能取到文字。
· 关闭：点卡片外、Esc、滚动、换章或翻页。Esc 只关卡片，不退出阅读页。
· 卡片贴在标记旁，下方放不下就翻到上方；宽度与最大高度夹在视口内。

18.7 搜索的边界（对 §17.3 的补充）

· PDF 走 pdf.js 的文字层：逐页取文本片段、压缩空白、全角转半角后匹配，命中区间映射回原文再显示。
· 按页缓存，200 条上限；扫页过程中面板显示「第 N / M 页」。
· 扫描件（图片型 PDF）没有文本片段，此时面板明确说明原因，不回一个空结果了事。

18.8 交互冲突的取舍

· 分页模式不再铺透明热区层（那会挡住正文，导致无法划词），翻页改为在舞台上按点击位置分区（左 25% / 中 50% / 右 25%）。
· 存在选区时，轻点只取消选择、不翻页；点划线只弹提示、不翻页；点脚注卡片不参与分区判定。
· 工具栏、抽屉、浮条、脚注卡片都不参与翻页分区判定。
