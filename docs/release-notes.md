**把小说、漫画、PDF 收进同一个书架的本机阅读器。** 不联网、不要账号、不推书——书是你的文件，阅读记录是本机的一个 SQLite 文件。

这是 **1.0.0 的修复版**，只改了一处：PDF 点击左右两侧不翻页。

## 下载哪个

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows 安装版 | `Cenro_1.0.1_x64-setup.exe` | 装到当前用户目录，不需要管理员 |
| Windows 免安装 | `Cenro-1.0.1-win-x64-portable.exe` | 双击即用 |
| Android | `Cenro-1.0.1-android-arm64.apk` | 需要 8.0+，只含 arm64-v8a |

Windows 需要 WebView2：Win11 自带，Win10 缺失时装一次 Evergreen Runtime。
若打开后黑屏或画面错乱（少数 Intel 核显、远程桌面、虚拟机会遇到），
下载 `Cenro-1.0.1-compat-mode.bat` 放到 exe 同目录，双击它启动即可。

## 这一版修了什么

- **PDF 点左右两侧不翻页**（1.0.0 引入）。1.0 给 PDF 加了可选中的文字层用来划词，
  这层透明文字盖满整页，把原来叠在画布上的翻页热区挡住了——点击全被文字接走，
  只有页面两侧那点空白还能翻页。
- 现在按点击位置分区：**左 25% 上一页、右 25% 下一页、中间不动**。
  拖动或长按（选字）不会误翻；有选区时点一下只取消选择，不跳页。
- 选字划线照旧，两件事不再互相挤占。

其余功能与 1.0.0 完全一致：12 种格式、PDF 划线与批注、标注导出与回导、书内搜索、
标签与批量导出、脚注弹窗、自定义字体、隐私书架、WebDAV 备份。

完整的能读什么、数据放在哪、怎么从源码构建，见仓库 README；逐版本变更见 CHANGELOG。

源码同步自 [GitHub](https://github.com/Lumivox-wiz/Cenro)，本仓库为国内镜像。
