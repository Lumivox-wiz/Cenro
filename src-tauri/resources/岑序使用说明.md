# 岑序 · 使用说明

这本书随安装包一起放进书架，讲「怎么用」，也讲「为什么这么做」。看完可以直接删掉，不影响任何功能。
删了之后升级不会再塞回来——想再看，装一次新版本就有了（旧记录不会被覆盖）。

## 一、把书放进来

四种方式，按场景选：

1. **导入文件**：顶栏「导入」，可多选。文件会被**复制**进应用自己的目录，
   原文件删了也不影响书架——安卓上尤其重要，微信收到的文件随时会被清理。
2. **添加目录**（桌面端）：设置 → 书库 → 目录，指定一个文件夹，之后点「扫描」自动收书。
   适合电脑上已经整理好的书库。手机上系统沙箱不允许整目录读取，只能用「导入文件」。
3. **拖拽**（桌面端）：把文件或文件夹拖进窗口任意位置。
4. **双击 / 用其他应用打开**：装好之后，系统里双击一本书、
   或者在文件管理器、微信里选「用其他应用打开 → 岑序」，都会直接进书架并打开。
   应用已经开着时不会弹第二个窗口，参数会转交给它。

支持的文字格式：TXT、Markdown、HTML、EPUB、MOBI、AZW3、FB2、DOCX、RTF、MHTML；
表格：XLSX；版式：PDF、OFD；漫画：CBZ、CBR、CBT、CB7、ZIP、图片文件夹。

MOBI 与 ZIP 按**内容**判断：里面图片 ≥ 3 张就当漫画读，否则当文字书。

## 二、书架

- 左侧（手机上在顶栏下拉）按**格式族**分类：文本、电子书、文档、漫画、PDF，另有「最近阅读」。
  一本书只属于一个分类，各分类的数字加起来正好等于「全部」。
- 顶部可切换**网格 / 列表**、排序（最近阅读 / 添加时间 / 书名）、按书名或作者搜索。
- 手机网格三列；窗口宽到 1440 以上时，漫画与 PDF 可以切双页。
- **标签**：右键（手机上长按）卡片 →「标签…」，输入后回车添加，也可以点已有标签直接复用。
  贴好之后侧栏会多出「标签」一栏，点一下就筛出这一类。标签与分类可以**叠加**：
  先点「漫画」再点「待读」，看到的就是「还没读的漫画」；再点一次已选标签即取消。
  标签与分类是两件事——分类由格式决定，一本书只能落一格；标签是你自己贴的。
- 右键菜单：打开 / 在文件夹中显示 / 编辑信息 / 标签 / 从书架移除 / 删除本地文件。
  「从书架移除」只删记录，5 秒内可撤销；「删除本地文件」会进系统回收站（手机上直接删，没有回收站）。
- **批量**：顶栏「多选」勾选若干本，底部可以
  - **导出文件…**：把选中的书**复制**到你挑的文件夹（原文件不动）。目标文件夹里有同名文件会自动加 `(1)`，不覆盖。
  - **移入隐私书架**：见第六节。
- **统计与维护**（设置 → 书库）：在架 / 在读 / 已读完 / 未开始、分类分布、最近 7 天；
  另外可以看缓存占用并清理、批量重建封面。
- 卡片异常态：文件被外部移走时置灰并标「文件已丢失」，点开可选「重新定位」或「从书架移除」。
  换电脑、挪文件夹之后遇到这个提示，用「重新定位」指回新位置即可，进度与标注都还在。

## 三、阅读

- **翻页**：← / →、空格、J / K；手机点屏幕左右两侧。分页与连续滚动两种模式都可用。
- **目录**：顶栏目录按钮或按 T，目录里可以直接搜索章节。
- **进度**：底部进度条可拖动；退出再进会回到上次的位置。
- **脚注**：EPUB / HTML 里点正文中的数字标记，注释浮在旁边，点空白处或 Esc 收起，
  不会再把你甩到章末。跨文件的注释链接（指向「注释.xhtml」）仍按普通链接跳转。
- **排版**（设置 → 阅读）：字号、行高、字体（衬线 / 黑体 / 楷体 / 等宽）、段间距、页边距、版心宽度。
  桌面端还能给**中文**与**西文**各选一个字体文件（ttf / otf / ttc / woff）：
  西文只吃字母与数字，汉字仍用中文字体，两者互不干扰；手机不开放这一项。
  版心宽度只影响桌面端，手机上永远按屏宽排版。
- **快捷键说明**：每个阅读页顶栏的 `?`，只列出当前格式真正可用的键位。
- 漫画：默认日漫方向（右→左），按 D 切单页 / 双页；条漫模式按视口滚动。
- 手机：返回键按界面层级逐级退出（先关面板，再退出阅读，最后回书架）。

## 四、标注：书签 · 划线 · 笔记

顶栏的标注按钮打开的是**标注**面板，三类东西放在同一张列表里，靠徽标区分。

### 书签

- 面板顶部「在当前位置加书签」，默认备注是「第 N 章 · 42%」。
- 每条可以重命名（铅笔图标，回车保存）、删除（6 秒内可撤销）、跳转。
- 同一位置重复加不会生成两条，只提示「这个位置已有书签」。

### 划线高亮与笔记

覆盖 TXT / HTML / EPUB / **PDF**。PDF 的文字可以像网页一样直接选（拖选、双击选词都行），
选中后同样浮出操作条；划线按「哪一页 + 哪块区域」记录，放大缩小、换窗口宽度、切单双页都不会画偏。
扫描件 PDF 没有文字层，选不了字，只能加书签。

- 在正文里**选中一段文字**，旁边浮出「高亮 / 笔记」。高亮一键完成；
  笔记多一个输入框，写的内容和这段原文一起存下来。
- 高亮是正文下面一条荧光带，笔记是另一色带子加虚线下划线——一眼能分清
  「这句只是标出来」和「这句我写了想法」。
- 划线跟着章节走：换章、退出重进都还在；跳到某一章会自动把该章的划线画回去。
  在面板里点一条划线会**精确翻到它所在的那一页**，不是只跳到那一章。
- 划线记的是「第几个字到第几个字」，所以改字号、改行高、换字体、切分页 / 滚动都不影响。
  唯一会失效的情况是书本身换了内容——这时宁可少画一条，也不会把线画到别的句子上。

### 面板

- 条目多于一条时出现**类型筛选**（全部 / 书签 / 高亮 / 笔记）和「按位置 / 按时间」排序。
- 右上角下载按钮**导出**：文件名用 `.md` 出 Markdown，用 `.csv` 出表格，用 `.json` 出**可回导**的备份。
  Markdown 里书里的原话是引用块、你自己写的是正文段落，分得很清。
- 旁边上传按钮**导入**（只认 `.json`）：同一份文件导入两次不会重复，重复的条目算进「跳过」。
  Markdown 与 CSV 是给人看的，位置被四舍五入过，所以不做导入——否则会得到一堆错位的书签。
- 手机上暂不提供导出与导入，请到电脑上操作。

## 五、书内搜索

- 顶栏放大镜 → 输入关键词回车。结果给出章节名 + 上下文，命中词加粗，点一条直接跳过去。
- 覆盖文字类与表格类格式、EPUB，以及**文字版 PDF**：在 PDF 的文字层里逐页找，
  大文件扫页时会显示「第 N / M 页」，不会像卡死。
- 中文 PDF 里字与字常被排版拆开（「低 碳材料」）、数字常是全角（「２０１６」），
  这些都能搜到——匹配前会先做归一化。
- 扫描件 PDF（每页是图片）与漫画没有文字层，搜不到；面板会说明原因，而不是回一个空列表。
- 搜索每次现算，不落库；划线与笔记才会存下来。
- 上限 200 条，够了就停。EPUB 的跳转位置按字符比例估算，落在附近而不是精确到某一行。

## 六、隐私书架

- 设置 → 隐私：设一个六位 PIN，可以设定「多久没操作就自动上锁」。
  书架顶部标题「岑序」长按 0.8 秒进入。
- 移入：主书架「多选」勾选 → 底部「移入隐私书架」；移出在隐私书架里同样操作。
- 移入后这些书在公开书架里**完全看不到**：搜索、最近阅读、分类计数、统计里都没有它们，
  封面也挪到了另一个目录。
- 上锁状态下点开只会看到 PIN 输入框，连续输错会有退避等待。
- 备份默认**不含**隐私书（连书签与备注都不进包）。需要的话在备份页勾选。
- **只做可见性隔离，不加密文件**：书和进度还在磁盘上，挡住的是「别人拿起设备翻两下」，
  不是取证。真正的隐私要等文件加密。

## 七、备份与换机

- 设置 → 备份：导出本地 zip（也可以「快速备份」到应用数据目录），或传到 WebDAV。
  超出设定份数时自动清理最旧的。
- 备份包含：书籍记录、阅读进度、标注与标签、封面、配置。
- 恢复是**整库替换**：先替换数据库再重指封面路径，旧封面会被清掉。书籍文件本身不动——
  换机时先把书拷到新机器、再恢复备份，进度与标注就都接上了。
- 只搬标注、不搬整库：见第四节的 JSON 导出 / 导入，同一本书在另一台机器上导入即可。
- 隐私书的标注不进备份，同理也不会被恢复出来。

## 八、外观

- **主题**（设置 → 主题）：浅色 / 深色 / 跟随系统；阅读区可单独选纸面（浅色 / 深色 / 护眼 / 纯黑 / 跟随应用）。
- **材质**：与主题是两个维度。「液态玻璃」既可以是亮玻璃也可以是暗玻璃，
  所以它不放在主题下拉里。
- **背景**（设置 → 背景）：书架背景图，可调填充方式、不透明度、模糊与纸色遮罩，只作用于书架层。
- **莫奈取色**：从背景图取主色相，只接管强调色、选中底与光晕，纸面与文字颜色不动——
  那是可读性的地基。灰阶图会自动关闭并提示。

## 九、出问题时

- 设置 → 关于 → **运行日志**：启动、扫描、备份、隐私开关、错误都会记进来。
  出问题先看这里，比「刚才弹了个错」有用得多；可以一键复制全部。
- 设置 → 关于 → **布局自检**：打印顶栏、侧栏、抽屉、阅读栏的实际尺寸与安全区数值。
  遇到「被刘海挡住」「文字叠在一起」，把这段发出来比截图更准。
- **安卓上打开只看到「WebView 版本过旧」**：安卓的网页内核（Android System WebView）由系统更新，
  太久没更新就跑不动。到应用商店更新它（有些机型归在 Chrome 里），再重新打开即可。
- **窗口一片黑 / 画面错乱**：多半是 WebView2 的 GPU 合成在这台机器上失败（常见于部分 Intel 核显、
  远程桌面与虚拟机）。把随包的「兼容模式启动.bat」放到 exe 同一目录，双击它启动即可绕过合成层；
  它只对这一次运行生效，不改系统设置。
- 日志位置：`<应用数据目录>/logs/cenro.log`，超过 2 MB 自动轮转，保留三份。
- 数据目录（Windows）：`%APPDATA%\com.lumivox.cenro\`。
  安卓在应用私有目录里，卸载即删，文件管理器和 USB 都看不到。

## 十、几个设计取舍

- **本地优先**：不联网、不注册、不采集。书与进度都在你自己机器上。
- **不做云同步**：那需要账号体系与服务端，和「本地优先」冲突。替代方案是 WebDAV 备份，
  够用且不引入账号。
- **导入是复制，不是引用**：源文件多在下载、微信接收目录里，随时会被清理。
  代价是同一本书占两份空间——可以接受，因为书不大，而丢书很难受。
- **EPUB 不算「已读完」**：它只记录章内位置，折不出全书百分比。
  统计里宁可把 EPUB 计入「在读」，也不给一个假的完成度。
- **扫描件 PDF 与漫画搜不到**：前者的文字在图片里，后者整本都是图片，要做得引入 OCR。
- **书架不显示标签徽标**：卡片上信息已经够密，标签只在侧栏与弹窗里出现。
